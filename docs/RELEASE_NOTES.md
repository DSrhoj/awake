# Awake 1.0.0

**Tag:** `v1.0.0`  
**Title:** `Awake 1.0.0`

## Release notes (GitHub body)

```markdown
## Awake 1.0.0

First public release of **Awake** — a menu bar utility that temporarily keeps your Mac awake without changing System Settings.

### Highlights
- **Keep Awake** — block idle system sleep and/or display sleep independently
- **Timed sessions** — until turned off, or auto-off after 15m / 30m / 1h / 3h
- **One-shots** — Lock Screen, Sleep Display, Sleep Mac
- **Launch at Login** via `SMAppService`
- Menu bar only (no Dock icon); eye icon opens when an override is active

### Install
1. Download **Awake-1.0.0.zip** (or the `.dmg`)
2. Drag **Awake.app** into **Applications**
3. First open: **right-click → Open** (ad-hoc signed; not notarized)

### Requirements
- macOS 26 or later

### Notes
- Quitting Awake releases all overrides
- Lid close, Apple menu Sleep, and critical battery still win
```
