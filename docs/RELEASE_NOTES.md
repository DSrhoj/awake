# Awake 1.1.0

**Tag:** `v1.1.0`  
**Title:** `Awake 1.1.0`

## Release notes (GitHub body)

```markdown
## Awake 1.1.0

### What's new
- **Disable Mission Control Swipe** — temporarily turn off 3- and 4-finger Mission Control (and App Exposé) trackpad swipes
- **With Keep Awake** — optional preference to auto-disable the swipe whenever Keep Awake is on

### Install
1. Download **Awake-1.1.0.zip** (or the `.dmg`)
2. Drag **Awake.app** into **Applications**
3. First open: **right-click → Open** (ad-hoc signed; not notarized)

### Requirements
- macOS 26 or later

### Notes
- Quitting Awake restores Mission Control swipe prefs and releases sleep overrides
- Lid close, Apple menu Sleep, and critical battery still win
```
